# Гриф — тренажёр электрогитары и баса

Веб-приложение для ежедневных занятий по 30 минут: тюнер, метроном, упражнения с проверкой игры по звуку, программа по неделям (гранж, рэп-метал, популярный рок), табы через alphaTab, гармония и статистика.

Сайт: https://nbscom.github.io/grif/

## Вход с гитары
Подключите процессор (например, Mooer GE) по USB, откройте вкладку «Тюнер» и нажмите «Включить вход». Устройство Mooer выбирается автоматически, если найдено. Захват идёт без эхоподавления, шумоподавления и автоусиления; высота определяется алгоритмом YIN в AudioWorklet (от ~36 Гц, хватает для баса в Drop D).

Для оценки «рано/поздно» один раз выполните «Калибровать задержку» на вкладке «Тюнер».

## Локальный запуск
```
python3 -m http.server 8765
```
и откройте http://localhost:8765 (микрофон работает только по HTTPS или на localhost).

## Структура
- `index.html`, `css/app.css` — разметка и стили
- `js/core.js` — состояние, строи, аккорды, гармония
- `js/audio.js` — синтез струн, планировщик на часах Web Audio
- `js/input.js`, `js/pitch-worklet.js` — аудиовход, атаки и высота тона
- `js/library.js` — оригинальные упражнения и рифы, конвертация в alphaTex
- `js/exercises.js`, `js/plan.js`, `js/songs.js`, `js/progress.js`, `js/tuner.js`, `js/metronome.js`, `js/harmony.js` — вкладки
- `vendor/` — alphaTab 1.8.0 (MPL-2.0), шрифт Bravura (OFL), саундфонт Sonivox

Данные занятий хранятся в браузере (localStorage, файлы табов — в IndexedDB). Резервная копия — вкладка «Прогресс».
